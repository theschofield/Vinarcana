**Meta-lesson from the split-session experiment (user-confirmed):** the prompt transfers rules but
not calibration; this history file is the calibration. Read it BEFORE the prompt. Two independent
drafters + the user splitting the difference is a valid production workflow, not a failure mode.

---

**Round-4 course correction:** quality dipped in r3 batch work. Diagnosis: drafting became
defensive (writing around the ban list) instead of speaking from omniscience. Produced bolted-on
second beats ("There it is.") and slogan-compression ("Nothing outruns a made-up mind"). Fix
codified in prompt: drafting mindset section (one true thing about life + second-beat-must-turn
rule + one sentence is complete); bans demoted to post-draft checklist.

**Round-5 course correction:** the fortune-teller frame elevated to the top of the prompt. Lines
are SPOKEN across a table by a devilishly charming spirit right after the card turns over.
Written-English cadence is the enemy ("Every piece was put exactly where…" vs the user's edit
"Every piece, placed exactly where…" — same words, different world). The char limit is pressure
toward natural speech, not compression. Also codified: don't name the wonder ("magic"/"sublime"
label the feeling instead of evoking it — the Temperance failure); direct address allowed as a
wink ("Bit stuck, are we?").
